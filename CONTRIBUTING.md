# Участие в FAMQCORE Bot

Спасибо за интерес к проекту. Помочь можно кодом, тестированием, документацией и идеями для сценариев Discord-сообществ.

## Сообщить об ошибке

1. Проверьте, нет ли похожей задачи в [Issues](https://github.com/famqcore/Discordbot/issues).
2. Если задачи нет — создайте новую и укажите:
   - ожидаемое и фактическое поведение;
   - шаги для воспроизведения;
   - версию Python, ОС и версию discord.py;
   - безопасный фрагмент лога из консоли или `logs/bot.log`.

Не публикуйте токен Discord, ID приватных каналов и персональные данные участников.

## Предложить улучшение

Создайте [Issue](https://github.com/famqcore/Discordbot/issues) с ответами на три вопроса: какую проблему решает идея, как должен выглядеть сценарий и как проверить результат.

## Pull Request

1. Сделайте fork и создайте ветку: `feature/название` или `fix/номер-issue`.
2. Внесите небольшое, сфокусированное изменение.
3. Добавьте или обновите тесты, если изменилось поведение.
4. Выполните проверки:
   ```bash
   cd src/app
   TOKEN=dummy python -m unittest discover -s tests -v
   ruff check .
   ruff format --check .
   ```
5. Откройте PR с кратким описанием, результатом проверок и ссылкой на Issue.

## Требования к коду

- Следуйте PEP 8; Ruff — источник истины для линтера и форматтера.
- Тексты, команды и параметры держите в `config.py`.
- Новая функция должна быть понятна из кода и документации.
- Не добавляйте секреты, рабочие `.env`, базы SQLite или логи в Git.

Подробная карта разделов доступна в [документации](docs/index.md).
