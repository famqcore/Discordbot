# Как помочь FAMQCORE Bot

Проект открыт для разработчиков, тестировщиков и авторов документации. Даже небольшое улучшение сценария или текста может сделать работу Discord-сообщества удобнее.

## Где начать

- **Python-разработчики:** выберите задачу в [Issues](https://github.com/famqcore/Discordbot/issues) или предложите свою.
- **Тестировщики:** разверните бота на тестовом сервере, пройдите сценарии из [commands.md](commands.md) и заведите баг с шагами воспроизведения.
- **Авторы документации и идей:** улучшайте формулировки, инструкции и пользовательские сценарии через Issue или Pull Request.

## Процесс

1. Найдите или создайте [Issue](https://github.com/famqcore/Discordbot/issues) и опишите, какую задачу берёте.
2. Создайте ветку `feature/что-делаете` или `fix/номер-issue`.
3. Внесите минимально необходимое изменение; тексты и параметры размещайте в `config.py`.
4. Добавьте тесты для нового поведения.
5. Перед PR выполните:
   ```bash
   cd src/app
   TOKEN=dummy python -m unittest discover -s tests -v
   ruff check .
   ruff format --check .
   ```
6. Откройте PR: что изменилось, зачем это нужно, как проверено и какой Issue закрывает.

## Стиль кода

- Соблюдайте PEP 8 и форматирование Ruff.
- Делайте функции небольшими, а изменения — сфокусированными.
- Комментируйте причины решений, а не очевидные действия.
- Не коммитьте токены, персональные данные, `.env`, SQLite-базы и логи.

Полная краткая памятка находится в [CONTRIBUTING.md](../CONTRIBUTING.md).
