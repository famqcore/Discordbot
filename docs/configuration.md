# Конфигурация

Настройки живут в двух местах: `.env` (всё, что зависит от конкретного сервера, и секреты) и `src/app/config.py` (тексты, названия, лимиты, кулдауны). Менять поведение бота можно без правки кода модулей.

## Переменные .env

### Обязательное

| Переменная | Что это |
|---|---|
| `TOKEN` | Токен Discord-бота из Developer Portal |

### ID объектов сервера

| Переменная | Что это |
|---|---|
| `TICKETS_CATEGORY_ID` | Категория, в которой создаются тикеты |
| `ROLE_APPLIED_ID` | Роль «подал заявку» |
| `ROLE_RECRUITER_ID` | Роль рекрутёра |
| `ROLE_OWNER_ID` | Роль владельца |
| `ROLE_DEP_OWNER_ID` | Роль зам. владельца |
| `ROLE_ADMIN_ID` | Роль админа |
| `ROLE_SUPPORT_ID` | Роль саппорта |
| `VOICE_CHANNEL_IDS` | ID голосовых каналов обзвона через запятую, в порядке подписей из `VOICE_CHANNELS` |
| `LOG_CHANNEL_ID` | Канал лог-центра |
| `LOG_THREAD_TICKETS_ID` | Ветка «📝-заявки» |
| `LOG_THREAD_DECISIONS_ID` | Ветка «⚖️-решения» |
| `LOG_THREAD_AFK_ID` | Ветка «🔴-afk» |
| `LOG_THREAD_CALLS_ID` | Ветка «🔊-обзвоны» |
| `LOG_THREAD_STATS_ID` | Ветка «📊-статистика» |
| `LOG_THREAD_ERRORS_ID` | Ветка «🚨-ошибки» |
| `LOG_THREAD_AUDIT_ID` | Ветка «🧾-аудит» |

Все они необязательные. Где взять ID: Discord, Настройки, Расширенные, Режим разработчика, дальше правый клик по объекту и «Копировать ID».

Проверки при разборе `.env`: значение должно состоять только из цифр и попадать в диапазон Discord ID. Два разных параметра не могут указывать на один и тот же объект, а количество `VOICE_CHANNEL_IDS` должно совпадать с количеством кнопок обзвона. Ошибки собираются в один список и показываются при старте.

### Сроки и интервалы

| Переменная | По умолчанию | Диапазон | Что делает |
|---|---|---|---|
| `TICKET_RETENTION_DAYS` | 180 | 1-3650 дней | Сколько храним заявки и транскрипты |
| `RETENTION_CHECK_SECONDS` | 86400 | 60-604800 сек | Как часто идёт очистка просроченных заявок |
| `AFK_EXPIRY_CHECK_SECONDS` | 60 | 10-86400 сек | Как часто снимаются истёкшие AFK |
| `TICKET_PROCESSING_TIMEOUT_SECONDS` | 300 | 30-86400 сек | Через сколько заявка в статусе `processing` считается зависшей |
| `TICKET_RECONCILE_CHECK_SECONDS` | 600 | 60-86400 сек | Как часто идёт сверка заявок и каналов |

### Время

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `GUILD_TIMEZONE` | `UTC` | Пояс сообщества: в нём разбирается ввод вида «23:45» и считается «день» для дневной статистики |
| `LEGACY_TIMEZONE` | `UTC` | Пояс, в котором старые версии бота писали время без зоны. Используется один раз, при миграции схемы до версии 4 |

Значения - имена IANA, например `Europe/Moscow`.

### Режимы работы

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `ENVIRONMENT` | `production` | Допустимо `production` или `development`. В production небезопасные режимы запрещены |
| `ALLOW_NAME_FALLBACK` | `false` | Возвращает поиск ролей и каналов по имени. Только для локальной разработки, вместе с `ENVIRONMENT=development` |

## Почему только ID

Бот ищет существующие объекты строго по ID. Имена в Discord не уникальны, и одноимённая роль не должна получить доступ к приватным тикетам, логам и праву решать по заявкам.

- **Заданный, но не найденный ID** - фатальная ошибка. После подключения бот выводит список проблем по каждому серверу и останавливается до обработки первой заявки. Мусор вроде `ROLE_ADMIN_ID=abc` отсекается ещё раньше, при разборе конфига.
- **Незаполненный ID** - не проблема. Роль просто не участвует в доступах, категорию тикетов и лог-центр бот создаст сам и запомнит их ID, а кнопка обзвона честно скажет, что канал не найден.
- **`ALLOW_NAME_FALLBACK=true`** - явный опт-ин для локального стенда: поиск по имени работает, проверки инфраструктуры становятся предупреждениями. В production конфиг с этим флагом просто не пройдёт валидацию.

Пути к базе (`DB_PATH`) и к логам (`LOG_DIR`) считаются от папки `src/app` и меняются только правкой `config.py`.

## Лог-центр

Один приватный канал со всеми отчётами бота. Внутри семь веток: `📝-заявки` (новые заявки), `⚖️-решения` (кто, что и почему решил), `🔴-afk` (уходы, возвраты, истёкшие), `🔊-обзвоны`, `📊-статистика`, `🚨-ошибки`, `🧾-аудит` (удаление данных и ретенция).

Есть два режима:

- **Бот управляет каналом сам** (`LOG_CHANNEL_ID` пуст). Он создаёт приватный канал и ветки (закрыто для `@everyone`, открыто боту и `STAFF_ROLE_IDS`) и запоминает ID в базе. Если кто-то ослабит права такого канала, бот вернёт приватные настройки и напишет предупреждение.
- **Готовый канал** (`LOG_CHANNEL_ID` задан, при желании и `LOG_THREAD_*_ID`). Каждый объект проверяется при старте и перед каждой отправкой: это текстовый канал или ветка этого же сервера, ветка принадлежит настроенному каналу, `@everyone` не видит канал, доступ есть только у бота и стафф-ролей. Задать ID веток без `LOG_CHANNEL_ID` нельзя, это ошибка конфигурации.

Принцип простой: не прошёл проверку приватности - ничего не отправляем. Никакого запасного канала и «похожего по имени» тоже. Отказ пишется в лог файла (ERROR или CRITICAL), а в production бот с небезопасным лог-центром не стартует. Заархивированную ветку бот пытается разархивировать, и ошибка логирования никогда не роняет основную логику.

Есть граница, которую проверка не покрывает: у ролей с правом Administrator доступ к любому каналу даёт сам Discord. Это вопрос доверия внутри сервера.

## Формы заявок

Формы описаны объектами, а не кортежами:

```python
RP_FORM = TicketForm(
    ticket_type="rp",
    title="RP ЗАЯВКА",
    fields=(
        TicketField("Никнейм в игре + статик", "Ваш игровой ник и статик", True, 100),
        ...
    ),
)
```

У поля четыре параметра: `label`, `placeholder`, `required`, `max_length`.

Лимиты Discord, за которые нельзя выходить (их проверяет валидация конфига при старте):

- не больше 5 полей в форме;
- `label` до 45 символов;
- `placeholder` до 100 символов;
- `max_length` от 1 до 4000.

Поля с `max_length` от 151 символа показываются многострочным полем, остальные однострочным.

Чтобы добавить третий тип заявки, опишите ещё один `TicketForm`, добавьте его в `TICKET_FORMS` и заведите кнопку в `TicketTypeView`.

## Настройки AFK

| Переменная | Значение | Описание |
|---|---|---|
| `AFK_COOLDOWN_SECONDS` | 30 | Кулдаун автоответа на пару «кто упомянул - кто в AFK» |
| `AFK_NICK_PREFIX` | `[AFK] ` | Префикс ника |
| `AFK_MIN_DURATION_MINUTES` | 1 | Минимальная длительность AFK |
| `AFK_MAX_DURATION_MINUTES` | 43200 | Максимум, это 30 суток |
| `AFK_MAX_MENTIONS_PER_MESSAGE` | 5 | Сколько упоминаний проверяем в одном сообщении |
| `AFK_REPLY_CHANNEL_LIMIT` | 3 | Автоответов на канал за окно |
| `AFK_REPLY_CHANNEL_WINDOW_SECONDS` | 20 | Длина окна |
| `AFK_REPLY_DELETE_AFTER_SECONDS` | 60 | Через сколько удаляется автоответ |
| `AFK_REASON_INPUT_MAX_LENGTH` | 100 | Лимит поля причины |
| `AFK_DURATION_INPUT_MAX_LENGTH` | 50 | Лимит поля времени |

Тексты AFK тоже в конфиге, все с префиксом `AFK_`:

| Группа | Переменные |
|---|---|
| Заголовки и меню | `AFK_EMBED_TITLE`, `AFK_EMBED_DESCRIPTION`, `AFK_MENU_TITLE`, `AFK_MENU_NO_AFK`, `AFK_MENU_TOTAL` |
| Форма ухода | `AFK_MODAL_TITLE`, `AFK_MODAL_REASON_LABEL`, `AFK_MODAL_REASON_PLACEHOLDER`, `AFK_MODAL_DURATION_LABEL`, `AFK_MODAL_DURATION_PLACEHOLDER` |
| Возврат | `AFK_RETURN_MODAL_TITLE`, `AFK_RETURN_CONFIRM`, `AFK_RETURN_DURATION_LABEL`, `AFK_RETURN_EXPIRED` |
| Кнопки | `AFK_BUTTON_LEAVE`, `AFK_BUTTON_RETURN`, `AFK_BUTTON_REFRESH`, `AFK_BUTTON_STAY` |
| Сообщения | `AFK_RETURN_SUCCESS`, `AFK_RETURN_STAY`, `AFK_RETURN_ERROR`, `AFK_NOT_AFK`, `AFK_INVALID_USER`, `AFK_REASON_DEFAULT`, `AFK_NO_PERMISSION`, `AFK_GUILD_ONLY` |
| Статус и проверка | `AFK_AFK_STATUS`, `AFK_CHECKED_NOT_AFK`, `AFK_FIELD_*` |
| Статистика | `AFK_STATS_TITLE`, `AFK_STATS_NO_DATA`, `AFK_STATS_TOTAL`, `AFK_STATS_TOTAL_TIME`, `AFK_STATS_LONGEST` |
| Логи и автоответ | `AFK_LOG_SET_TITLE`, `AFK_LOG_REMOVED_TITLE`, `AFK_LOG_EXPIRED_TITLE`, `AFK_EXPIRED_DM`, `AFK_AUTO_REPLY` |

`AFK_AUTO_REPLY` это шаблон с подстановками `{mention}`, `{reason}` и `{duration}`.

Переменные `AFK_VOICE_RETURN_TITLE` и `AFK_VOICE_RETURN_DESC` остались от старого поведения, когда вход в голосовой канал снимал AFK. Сейчас код их не использует.

## Примеры правок

Сменить префикс команд:

```python
CMD_PREFIX = "."
```

Сделать кулдаун автоответа минутным:

```python
AFK_COOLDOWN_SECONDS = 60
```

Добавить поле в CAPT-форму (помним про максимум 5 полей и 45 символов в label):

```python
CAPT_FORM = TicketForm(
    ticket_type="capt",
    title="CAPT ЗАЯВКА",
    fields=(
        ...,
        TicketField("Опыт в каптах", "Сколько заходов сыграли", False, 100),
    ),
)
```

## Когда изменения вступают в силу

Только после перезапуска. И `.env`, и `config.py` читаются один раз при импорте модулей.
