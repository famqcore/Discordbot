# Настройка

Все настройки бота - в `src/app/config.py` и `.env`. Идея проекта: менять поведение можно без правки кода.

## .env

| Переменная | Что это | Обязательно |
|------------|---------|-------------|
| `TOKEN` | Токен Discord-бота из Developer Portal | Да |
| `TICKETS_CATEGORY_ID` | ID категории для тикетов | Нет |
| `ROLE_APPLIED_ID` | ID роли «подал заявку» | Нет |
| `ROLE_RECRUITER_ID` | ID роли рекрутёра | Нет |
| `ROLE_OWNER_ID` | ID роли владельца | Нет |
| `ROLE_DEP_OWNER_ID` | ID роли зам. владельца | Нет |
| `ROLE_ADMIN_ID` | ID роли админа | Нет |
| `ROLE_SUPPORT_ID` | ID роли саппорта | Нет |
| `VOICE_CHANNEL_IDS` | ID голосовых каналов обзвона через запятую (в порядке `VOICE_CHANNELS`) | Нет |
| `LOG_CHANNEL_ID` | ID канала лог-центра | Нет |
| `LOG_THREAD_TICKETS_ID` | ID ветки «📝-заявки» | Нет |
| `LOG_THREAD_DECISIONS_ID` | ID ветки «⚖️-решения» | Нет |
| `LOG_THREAD_AFK_ID` | ID ветки «🔴-afk» | Нет |
| `LOG_THREAD_CALLS_ID` | ID ветки «🔊-обзвоны» | Нет |
| `LOG_THREAD_STATS_ID` | ID ветки «📊-статистика» | Нет |
| `LOG_THREAD_ERRORS_ID` | ID ветки «🚨-ошибки» | Нет |
| `AFK_EXPIRY_CHECK_SECONDS` | Интервал проверки истёкших AFK, сек (60 по умолчанию) | Нет |

ID смотрятся так: Discord → Настройки → Расширенные → Режим разработчика → правый клик по каналу/роли → «Копировать ID».

Бот работает по ID. Если какой-то ID не задан, объект ищется по имени из `config.py` - это намеренный запасной вариант, но по имени работать хрупко (переименуете - бот не найдёт). Пути до базы (`DB_PATH`) и до логов (`LOG_DIR`) считаются от папки `src/app` и переопределять их сейчас нельзя - только правкой `config.py`.

## Лог-центр

Один приватный канал для всей отчётности бота. Внутри - 6 веток: `📝-заявки` (новые заявки), `⚖️-решения` (принял/отклонил, кто и почему), `🔴-afk` (входы, выходы, истёкшие), `🔊-обзвоны` (кто кого вызвал и куда), `📊-статистика`, `🚨-ошибки`.

- Канал резолвится по `LOG_CHANNEL_ID`, иначе создаётся автоматически: закрыт для `@everyone`, открыт боту и стафф-ролям (`STAFF_ROLE_IDS`).
- Ветки резолвятся по `LOG_THREAD_*_ID` из `.env`; если ID нет - создаются автоматически по именам из `LOG_THREAD_NAMES`.
- Если ветка недоступна (удалили, нет прав), бот шлёт в корень канала и пишет предупреждение в консоль; ошибки логирования не роняют основную логику.

### Поля форм RP_FIELDS и CAPT_FIELDS

Каждое поле - кортеж из четырёх значений:

```python
("Никнейм в игре + статик", "Ваш игровой ник и статик (если есть)", True, 100)
#  ^label                     ^placeholder                             ^required ^max_length
```

Жёсткие лимиты Discord, выход за которые сломает форму:

- полей в форме — максимум **5**
- `label` — максимум **45** символов
- `placeholder` - максимум **100** символов
- `max_length` - от 1 до 4000

Поля с `max_length` больше 150 вводаются многострочным полем, остальные - однострочным.

### Настройки AFK

| Переменная | Значение | Описание |
|------------|----------|----------|
| `AFK_COOLDOWN_SECONDS` | `30` | Кулдаун автоответа на упоминание для пары «кто упомянул - кто в AFK» |
| `AFK_NICK_PREFIX` | `[AFK] ` | Префикс ника у AFK-пользователя |

Все тексты AFK тоже в конфиге, группа `AFK_*`:

| Группа | Переменные |
|--------|-----------|
| Заголовки | `AFK_EMBED_TITLE`, `AFK_EMBED_DESCRIPTION`, `AFK_MENU_TITLE`, `AFK_MENU_NO_AFK`, `AFK_MENU_TOTAL` |
| Модальное окно взятия | `AFK_MODAL_TITLE`, `AFK_MODAL_REASON_LABEL`, `AFK_MODAL_REASON_PLACEHOLDER`, `AFK_MODAL_DURATION_LABEL`, `AFK_MODAL_DURATION_PLACEHOLDER` |
| Окно возврата | `AFK_RETURN_MODAL_TITLE`, `AFK_RETURN_CONFIRM`, `AFK_RETURN_DURATION_LABEL` |
| Кнопки | `AFK_BUTTON_LEAVE`, `AFK_BUTTON_RETURN`, `AFK_BUTTON_REFRESH`, `AFK_BUTTON_STAY` |
| Сообщения | `AFK_RETURN_SUCCESS`, `AFK_RETURN_STAY`, `AFK_RETURN_ERROR`, `AFK_NOT_AFK`, `AFK_INVALID_USER`, `AFK_REASON_DEFAULT` |
| Статус и проверка | `AFK_AFK_STATUS`, `AFK_CHECKED_NOT_AFK` |
| Статистика | `AFK_STATS_TITLE`, `AFK_STATS_NO_DATA`, `AFK_STATS_TOTAL`, `AFK_STATS_TOTAL_TIME`, `AFK_STATS_LONGEST` |
| Автоответ | `AFK_AUTO_REPLY` - шаблон с `{mention}`, `{reason}`, `{duration}` |
| Возврат через голос | `AFK_VOICE_RETURN_TITLE` (шаблон с `{user}`), `AFK_VOICE_RETURN_DESC` |

## Примеры правок

Сменить префикс команд:

```python
CMD_PREFIX = "."
```

Сменить кулдаун автоответа на минуту:

```python
AFK_COOLDOWN_SECONDS = 60
```

Добавить поле в CAPT-форму (помним: максимум 5 полей, label до 45 символов):

```python
CAPT_FIELDS = [
    ...("Опыт в каптах", "Сколько заходов сыграли", False, 100),
]
```

## Когда бот подхватывает изменения

Только при перезапуске. Конфиг читается один раз при импорте модулей.
