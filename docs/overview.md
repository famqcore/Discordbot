# Обзор FAMQCORE Bot

FAMQCORE Bot решает три задачи игрового Discord-сообщества: собрать заявки, обработать их в приватных тикетах и понимать, кто сейчас на месте, а кто в AFK.

## Как это выглядит на практике

1. **Заявка.** Участник пишет `!famqcore`, выбирает тип заявки (RP или CAPT) и заполняет форму из пяти полей. Бот выдаёт роль «Подал заявку», пишет человеку в личку и открывает приватный канал под заявку.
2. **Рекрутинг.** В канале заявки у модераторов есть четыре кнопки: принять, отказать, вызвать на обзвон, закрыть тикет. Решение требует причины, и всё уходит в лог-канал вместе с транскриптом переписки.
3. **AFK.** Человек указывает причину и время возврата. Пока он в AFK, бот отвечает на упоминания и держит префикс `[AFK]` в нике. Статус снимается по времени, кнопкой или модератором.
4. **Контроль.** Админы видят сводку `!stats` и историю `!history`, могут удалить данные участника командой `!delete_user_data`. Данные разных серверов друг с другом не пересекаются.

## Что уже работает

- две формы заявок и приватные каналы под каждую;
- защита от второй одновременной заявки от одного человека;
- лог-центр: один приватный канал и семь веток по типам событий;
- AFK со статистикой, автоответами и автоснятием по времени;
- миграции SQLite и разделение данных по `guild_id`;
- удаление персональных данных по команде админа и автоматическая очистка старых заявок;
- фоновая сверка состояний (если канал тикета удалили руками, запись в базе не зависнет);
- Docker-образ без root, hash-locked зависимости, тесты и Ruff в GitHub Actions.

## Технологии

- Python 3.11 (под эту ветку собраны lock-файлы и Docker-образ);
- discord.py 2.7 с префиксными командами;
- SQLite через стандартный `sqlite3`, схема версии 4;
- Docker и Docker Compose;
- unittest, coverage, Ruff, pre-commit, GitHub Actions.

## Статус

Проект развивается. Приоритеты простые: не терять данные, предсказуемо работать сразу на нескольких серверах и не мешать модераторам. Планы - в [дорожной карте](roadmap.md), текущие задачи - в [Issues](https://github.com/famqcore/famqcore_discord/issues).
