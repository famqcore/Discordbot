# Обзор проекта

## Для чего этот бот

Regent FamQ Bot — инструмент автоматизации для игровых семей на RP-проектах: от приёма заявок до учёта активности и статистики.

1. **Приём заявок.** Пользователь нажимает кнопку, заполняет форму, получает приватный канал-тикет. Рекрутёр решает судьбу заявки кнопкой, всё пишется в лог и базу.
2. **AFK-учёт.** Участник отмечается как «отошёл» с причиной и временем возврата. На упоминание такого человека бот отвечает за него.
3. **Статистика.** Сколько заявок подано, сколько принято и отклонено, кто сколько времени провёл в AFK.

## Статус: бета

Проект в бета-стадии и только начинает активную разработку. Это значит:

- Основные сценарии работают, но в трекере есть известные баги. Они честно заведены в [Issues](https://github.com/yyangdev/majestick-famq-discord-bot/issues), там же их приоритет.
- Код местами требует рефакторинга, это запланировано в [roadmap](roadmap.md).
- Тексты и настройки можно менять без правки кода через `config.py`.

## Что уже работает

- Тикет-система
- Приватный лог-центр с тематическими ветками
- AFK: установка, снятие, список, автоответ, префикс ника, статистика
- Автотесты на unittest, линтер и форматтер Ruff с pre-commit и GitHub Actions
- Запуск в Docker

## Чего пока нет и почему честно об этом пишем

- Часть эксплуатационных задач ещё открыта: автоматические бэкапы, dependency-аудит, healthcheck и релизный процесс.
- Веб-панели (issue #13) - это долгосрочная цель после стабилизации backend.
- Данные заявок и AFK уже разделены по `guild_id`, миграции применяются при старте, один пользователь не может создать две открытые заявки на одном сервере.
