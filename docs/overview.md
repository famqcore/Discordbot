# Обзор FAMQCORE Bot

FAMQCORE Bot — инструмент для игровых Discord-сообществ: он принимает заявки, помогает рекрутёрам обрабатывать их в приватных тикетах, ведёт AFK-учёт и собирает статистику.

## Зачем нужен бот

1. **Заявки.** Участник открывает панель `!famqcore`, выбирает тип заявки и заполняет форму. Бот создаёт приватный канал, выдаёт роль и сохраняет заявку.
2. **Рекрутинг.** Уполномоченные участники принимают или отклоняют заявку, оставляя причину; действия попадают в лог.
3. **AFK.** Участник указывает причину и предполагаемое время возвращения. При упоминании бот отправляет автоответ, а статистика сохраняется.
4. **Контроль.** Администраторы получают сводку по заявкам и историю тикетов, а данные каждого Discord-сервера изолированы.

## Что уже есть

- тикет-система с двумя типами форм;
- приватный лог-центр с ветками по категориям;
- AFK-статусы, автоответы, список AFK и статистика;
- SQLite-миграции и разделение данных по `guild_id`;
- анонимизация пользовательских данных по запросу администратора;
- Docker, GitHub Actions, unittest, Ruff и pre-commit.

## Статус и развитие

Проект активно развивается. Приоритет — предсказуемая работа на нескольких серверах, безопасность данных и удобный опыт модерации. Задачи, ошибки и предложения ведутся в [GitHub Issues](https://github.com/famqcore/Discordbot/issues); планы — в [дорожной карте](roadmap.md).

## Технологии

- Python 3.10+
- discord.py 2.x
- SQLite
- Docker Compose
- unittest, Ruff и GitHub Actions
