# AFK-система

Учёт «отошедших» участников: статус с причиной, автоответ на упоминания, статистика.

## Как устроен цикл

1. `!afk` - бот показывает меню из трёх кнопок.
2. «🔴 Взять AFK» - открывается форма: причина (можно пустую) и время возврата.
3. После отправки формы бот:
   - записывает вас в таблицу `afk_users`,
   - плюсует счётчик уходов в `afk_stats`,
   - ставит нику префикс `[AFK] `,
   - отвечает вам лично (видите только вы) подтверждением.
4. Активность не снимает AFK: человек может писать в чат и говорить в голосовых
   каналах - статус остаётся. AFK снимается только:
   - по истечении указанного времени возврата (фоновая задача проверяет раз в минуту,
     интервал настраивается через `AFK_EXPIRY_CHECK_SECONDS`),
   - модератором командой `!afk_remove @user`,
   - самим пользователем кнопкой «🟢 Отменить AFK» с подтверждением.
5. При любом снятии восстанавливается ник (убирается префикс `[AFK] `) и считается
   длительность сессии. Все установки и снятия пишутся в ветку `🔴-afk` лог-центра,
   при истечении времени пользователю ещё приходит личное сообщение.

## Форматы времени возврата

Поле «На сколько?» понимает:

| Ввод | Как читается |
|------|--------------|
| `23:45` | Сегодня в 23:45; если время уже прошло - завтра |
| `1 час`, `2 часа` | Через N часов |
| `2 ч` | Короткая форма часов |
| `30 мин`, `30 минут` | Через N минут |
| `30 м` | Короткая форма минут |

Парсер простой и местами ошибается с хитрым вводом (issues #15 и #41). Если время не распознано - бот честно скажет «Не удалось распознать время» и AFK не поставит.

## Автоответ на упоминание

Если упомянуть человека в AFK, бот напишет в канал:

```
@user **в AFK**
Причина: ушёл есть
Ушёл: 12 мин назад
```

Сообщение самоудаляется через 60 секунд. Кулдаун: на пару «кто упомянул - кто в AFK» бот отвечает не чаще раза в 30 секунд (`AFK_COOLDOWN_SECONDS`).

Известные шероховатости, все в трекере:

- автоответ пингует AFK-пользователя ещё раз (#39);
- срабатывает на ответы-reply и на команды вроде `!afk_check @user` (#76, #88);
- если упомянуть сразу нескольких AFK - бот ответит по одному сообщению на каждого (#39).

## Ник [AFK]

- При взятии AFK ник становится `[AFK] Имя` (обрезается до лимита в 32 символа).
- При возврате префикс снимается.
- Если ник участника выше бота по роли - поменять не получится, бот молча пропустит (issue #43).
- Восстановление ника работает грубо: просто вырезает префикс. Если у человека был свой ник с «[AFK]» внутри - будет побочка, см. issue #24.

## Статистика

`!afk_stats @user` показывает:

- сколько раз человек уходил в AFK,
- суммарное время,
- самую долгую сессию.

Счётчики плюсуются при каждом взятии AFK, включая обновление причины у уже стоящего статуса - это известная ошибка подсчёта, issue #50.

## Автоснятие по времени

Когда указанное при взятии AFK время возврата наступает, фоновая задача снимает статус автоматически: восстанавливает ник, обновляет статистику, шлёт личное сообщение пользователю и пишет запись в ветку `🔴-afk` лог-центра. Заход в голосовой канал AFK больше не снимает - голосовая активность на статус не влияет.
